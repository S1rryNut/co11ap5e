# 10 · 转行面试准备

> 时长：最后 3~4 周。围绕"你有工程底子 + 能独立做 Agent 产品"这个定位来准备，别装资深算法工程师。

---

## 10.1 面试高频问题（按类型）

**基础概念类**
1. 什么是 Agent？和普通 LLM 调用/聊天机器人有什么区别？
2. ReAct 是什么？讲一下它的循环。
3. 什么是 MCP？Tools / Resources / Prompts 区别？
4. 什么是 RAG？为什么需要 RAG？它解决了什么问题？
5. Function Calling / Tool Calling 是怎么工作的？
6. 什么是上下文窗口？Agent 记忆怎么设计？
7. 提示注入是什么？怎么防护？

**设计类**
8. 如果让你设计一个"客服 Agent"，你会怎么搭？（考察：架构、工具、记忆、人工兜底、评估）
9. 你的 Agent 怎么防止幻觉？（检索引用 + 工具验证 + 明确"不知道"）
10. 多 Agent 什么时候该用？成本怎么控制？
11. Agent 无限循环怎么办？（循环上限 + 超时 + 人工中断）
12. 怎么评估一个 Agent 好不好？（评估集 + LLM-judge + 人工）

**项目深挖类（围绕你的作品）**
13. 讲一下你做的 Agent 项目，架构怎么设计的？
14. 遇到最难的问题是什么？怎么解决的？（说真实的坑）
15. 你的 RAG 项目怎么评估效果的？怎么优化的？
16. 上线后怎么监控？出问题怎么排查？（Langfuse 追踪、日志）

**工程能力类（你的强项，自信答）**
17. 你的项目怎么部署的？（systemd/nginx/Docker）
18. 密钥怎么管理的？（环境变量，不落仓库）
19. 怎么限流 / 控制成本？
20. 并发场景怎么处理？（asyncio / 消息队列）

## 10.2 需要能现场演示的东西

- **P5 毕业项目**：现场跑通一个完整任务（准备 2~3 个演示场景，提前录好兜底视频，避免现场翻车）
- **架构图**：能把项目画出来讲清楚
- **评估数据**：能说出"我优化了什么，效果提升了多少"

## 10.3 简历策略（转行向）

**定位**：不要写"资深后端"，写"全栈工程师 · 专注 LLM Agent 应用开发"。

**简历结构**（一页到两页）：
- 开头一句话定位："全栈工程师（Java/前端/Python），1 年 Agent 应用开发经验（个人项目）"
- **项目经历（放最前、占最大篇幅）**：3 个最有说服力的 Agent 项目，每个 3~4 条，写"技术栈 + 做了什么 + 量化效果"
- **技能**：Python / LangGraph / MCP / RAG(pgvector) / FastAPI / Nuxt / Docker / Linux / Java
- **工作经历**：客观写，强调与 AI 相关的部分（如"为团队搭建过 AI 工具链 OpenClaw/MCP 网关"）
- 你的**个人网站**就是加分项——放上链接，展示你已经开源维护一个完整产品

**给 HR/面试官的话术准备**：
- "我本来做传统 Web 后端，但一直在用 AI 工具做开发自动化，后来系统性学了 Agent 开发，做了 X 项目……"——用**项目**证明转型决心，比空谈热情有说服力。

## 10.4 求职渠道与节奏

- **渠道**：BOSS直聘 / 拉勾 / 内推（重点！找人内推 AI 公司）+ 开源社区（GitHub 活跃度会被看到）。
- **目标公司类型**：
  1. AI 创业公司（Agent 产品、RAG 产品）——最看重能干活、迭代快
  2. 大厂 AI 应用组（字节/阿里/腾讯的 AI 产品团队）
  3. 传统公司的 AI 转型部门（你的工程能力是优势）
- **节奏**：先投"练手"公司积累面试经验，再投心仪公司；每次面试后复盘被问到的题，补充到本文件。

## 10.5 面试模拟建议

- 用你自己的个人网站留言/聊天能力，或者找朋友模拟面试官。
- 把第 10.1 的问题列表过一遍，每道题能讲 1~2 分钟、有例子。
- 面试前把 P5 项目跑起来，演示链路顺一遍，确认网络/依赖不翻车。
